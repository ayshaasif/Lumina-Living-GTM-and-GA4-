### Project Title: **Lumina Contract – B2B Furniture & Interior Design Procurement Platform**

#### **Project Overview**

A responsive web application and digital storefront designed for B2B procurement, specifically tailored for interior designers, architects, and real estate developers looking to source commercial-grade furniture and request bulk quotes. Built using modern frontend development practices and integrated with cloud deployment and advanced analytics tracking.

#### **Key Features**

* **Dynamic Product Catalog:** Showcases curated commercial furniture lines, material finishes, and specifications optimized for interior design professionals.
* **Trade Quote Form:** Interactive lead-generation workflow enabling interior designers to submit custom project scope details, professional credentials, and estimated quantities.
* **Event-Driven Tracking & Analytics:** Fully integrated with Google Tag Manager (GTM) and Google Analytics 4 (GA4) utilizing custom data layer event pushes (`trade_quote_submitted`) to monitor and analyze high-intent B2B form submissions and user engagement.
* **High-Performance Deployment:** Hosted on a modern serverless cloud infrastructure (Vercel) ensuring lightning-fast asset delivery, global accessibility, and automated continuous deployment workflows.

#### **Tech Stack**

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Analytics & Tag Management:** Google Tag Manager (GTM), Google Analytics 4 (GA4), Data Layer API
* **Deployment & Hosting:** Vercel Cloud Platform, Git/GitHub Version Control
